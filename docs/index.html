Hardware Reference

Know your module

The ArdCore is an Arduino Nano in eurorack format. Two knobs, two CV jacks, a clock input, an 8-bit DAC output, and two digital outs.

K
Knob 1 & Knob 2
Potentiometers on A0 and A1. Read via analogRead() → 0–1023. Primary parameter controls for every sketch.
⇥
CV Inputs (A2 & A3)
Analog inputs for external CV. 0–5V range mapped to 0–1023. Use for voltage control of parameters, 1V/oct pitch, etc.
⏎
Clock Input
Digital pin 2 with interrupt. Use for external clocking, trigger inputs, gate detection. Rising edge triggers ISR.
⇤
DAC Output + D0 & D1
8-bit R-2R DAC on pins 5–12 via direct port writes (PORTB + PORTD). Two digital gate/trigger outputs on pins 3 & 4.
DSP Techniques

Integer math on 8-bit hardware

No floating point. No FPU. Everything is integer arithmetic on a 16MHz ATmega328P with 2KB of RAM. Here's how.

🔢
Fixed-point scaling
Multiply by integer, divide by power-of-2. Example: 0.7× becomes (long)val * 718L / 1024L. The compiler turns /1024 into a bit shift.
📐
Wavetable lookup
Store one cycle in PROGMEM as a 256-byte array. Phase accumulator indexes into the table. DDS gives you sub-Hz to audio-rate oscillators in a few lines.
⚡
Direct port writes
Skip digitalWrite() — write PORTB/PORTD directly for the 8-bit DAC. 4× faster. Essential for audio-rate output.
🎲
LFSR noise
Linear feedback shift register: XOR tapped bits, shift, repeat. A 16-bit LFSR gives 65535 unique values before cycling. One byte of state.
🧮
Overflow arithmetic
Use (long)a * b to avoid 16-bit overflow in intermediate results. Cast back to int after dividing. Critical for any multiplication of 10-bit values.
📈
Envelope state machines
Attack/decay/release as integer ramps. Increment by rate each loop. State variable tracks which phase is active. Output to DAC for amplitude control.
🔗
Clock interrupts
Attach interrupt to pin 2 (rising edge). Set a flag in the ISR, check it in loop(). Never do analogRead or DAC writes inside the ISR.
🧬
Chaotic maps
Logistic map, shift registers with nonlinear feedback, neuron models — all work beautifully in integer math. Small state, complex behavior.
VCV Rack → ArdCore

Port your favorite modules

We've ported SquidAxon, Genie, and Rungler from VCV Rack. Here's the workflow for porting your own.

Step 1
Map I/O
VCV modules have unlimited knobs and jacks. ArdCore has 2 knobs + 2 CV in + 1 clock + 1 DAC + 2 digital out. Decide what maps where. Self-exciting modules (chaos, oscillators) are easiest — they need fewer inputs.
Step 2
Kill the floats
Replace all float math with integer equivalents. 0.0–1.0 becomes 0–1023. Multiply-then-divide instead of fractional coefficients. Cast to long for intermediate products.
(long)val * 718L / 1024L // ≈ val × 0.7
Step 3
Watch the RAM
2KB total. Arduino runtime takes ~500 bytes. Avoid arrays over 256 elements. Use PROGMEM for lookup tables. One wavetable = 256 bytes = 12.5% of your RAM if not in flash.
Step 4
Document everything
Add I/O Usage header, algorithm explanation, ASCII diagrams in comments. Future you (and others) will thank you. Use the porting template in templates/.
cp templates/VCV_PORT_TEMPLATE.ino my_port/
